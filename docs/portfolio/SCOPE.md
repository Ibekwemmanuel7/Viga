## Domain and status

**Domain:** Oil-spill detection

**Status:** Awaiting owner-led separation from LillieWatch; documentation only.

## Current baseline

No LillieWatch code, data, credentials or infrastructure has been extracted into this repository by the portfolio work.

## Planned scope

Reusable oil-spill candidate detection, review and evidence workflows. After the owner publishes the separated code, review packaging, provenance, data rights, test evidence and regional suitability before selecting a source pin and integration method.

## Ownership and interfaces

Viga owns spill-related investigation outputs. Vaughan can provide flood/coastal event context and Velo water context. Candidate anomalies do not establish chemical concentration, source attribution, liability or cleanup completion. Methane measurement is not included in this scope.

## Delivery gate

Define the buyer, decision, last useful delivery time, reference data, baseline and acceptance criteria before implementation. Outputs must carry observation and processing dates, provenance, quality, uncertainty and unavailable-data states. Customer-provided records and assessments require explicit access control. No new operational or scientific performance claim follows from adding this roadmap.

The repository owns its reusable domain code, methods, tests and domain documentation. Lillie US owns cross-product integration, shared customer workflows, portfolio configuration and product-release coordination. Do not make this repository depend on Lillie US merely to create a backlink.
