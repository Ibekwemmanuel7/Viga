## Intended work

Reusable oil-spill candidate detection, review and evidence workflows. After the owner publishes the separated code, review packaging, provenance, data rights, test evidence and regional suitability before selecting a source pin and integration method.

## Relationship to Lillie US

Viga owns spill-related investigation outputs. Vaughan can provide flood/coastal event context and Velo water context. Candidate anomalies do not establish chemical concentration, source attribution, liability or cleanup completion. Methane measurement is not included in this scope.

This is an independent repository linked to the Lillie US portfolio. It has no installable application or runtime integration yet. See the [scope brief](docs/portfolio/SCOPE.md) for design requirements.
